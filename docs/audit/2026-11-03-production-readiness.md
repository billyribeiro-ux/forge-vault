# ForgeVault production-readiness audit — 2026-11-03

Scope: the whole app (React 19 + Vite+ web studio and the macOS Tauri v2 shell) at commit `1687237`, on branch `audit/production-readiness`. Tested on macOS (Darwin 25.6, Apple silicon) only. Windows and Linux were not built or tested.

The audit brief assumed Svelte/SvelteKit. This repo has no Svelte code, so the React, Vite+, and Tauri equivalents were applied.

## Summary of changes

### Data integrity (priority 1)

| Problem (evidence)                                                                                                                  | Fix                                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Every launch ran `indexedDB.deleteDatabase("forgevault_idb_v1")` without migrating it (old `vaultStorage.ts:44`).                   | The legacy database is no longer touched. Test: `upgrades a v2 database to v3 … leaves the v1 database alone`.                                                                                                                                                                  |
| Edits saved shortly before a reload or quit were lost. Reproduced: a prompt saved 30 ms before a reload was missing from IndexedDB. | Discrete saves write on the next tick and commit explicitly. Debounced writes flush on `visibilitychange`/`pagehide`. On quit, the native side holds the exit, emits `forgevault://flush-before-exit`, and exits on `confirm_exit` (3 s timeout). Re-test: the prompt survives. |
| Write errors were swallowed (`.catch(() => {})`).                                                                                   | Per-store errors are reported. The header shows "Saving…", "Saved", or "Not saved: …".                                                                                                                                                                                          |
| A failed load returned an empty vault, and the next change overwrote the stored data.                                               | Load errors show an error screen with Retry. Nothing is written until hydration succeeds. Test: `rejects instead of returning an empty vault`.                                                                                                                                  |
| Writes ran inside React state updaters, interleaved with rendering.                                                                 | One persistence effect per collection, gated on hydration, skipping the just-loaded arrays.                                                                                                                                                                                     |
| JSON restore accepted any object with two arrays and replaced data without asking.                                                  | `backupBundle.ts` validates every item, names the first invalid field, rejects duplicate ids, and shows a confirmation with counts and export date before replacing.                                                                                                            |
| IDs were `prefix-${Date.now()}`, which can collide within a millisecond.                                                            | `newId()` uses `crypto.randomUUID()`.                                                                                                                                                                                                                                           |
| Deleting a prompt was immediate with no recovery.                                                                                   | The toast offers Undo for 6 s. Deleting a folder also offers Undo.                                                                                                                                                                                                              |
| Closing the prompt editor (backdrop click or Escape) silently discarded edits.                                                      | The backdrop no longer closes it. Escape, ✕, and Cancel ask "Discard changes?" when there are unsaved edits.                                                                                                                                                                    |

### Security and offline

- **Monaco loaded from `cdn.jsdelivr.net` at runtime** (`@monaco-editor/loader` default), so the editors needed network access and did not work offline. Monaco 0.57 is now bundled with local workers (`monacoSetup.ts`). Verified: opening the reader made no requests to any other host.
- **Google Fonts** were loaded on every launch. They are now self-hosted through `@fontsource-variable/*`.
- **CSP was `null`.** It is now set in `tauri.conf.json`. Verified in Chromium against the production build served with the same header: zero `securitypolicyviolation` events, Monaco renders, fonts load, and a blob worker running an `AsyncFunction` (the sandbox mechanism) works. Not verified in WKWebView (see blockers).
- **Removed the "Tauri & Export" screen's GitHub installer.** It generated a script that ran `git remote remove origin`, re-added a hardcoded remote, and pushed. The screen also bundled the app's entire source into the JS through `import.meta.glob(?raw)`, linked to a nonexistent `/forge-vault.tar.gz` (404), and generated a `tauri.conf.json`/`Cargo.toml` that did not match the real files. It is replaced by **Backup & Data**.
- Removed `macOSPrivateApi`/`macos-private-api` (unused; blocks App Store distribution).
- Removed unused dependencies: `@google/genai`, `express`, `dotenv`, `motion`, `tsx`, `autoprefixer`, `@types/express`. `.env.example` no longer advertises Gemini/GitHub secrets.
- Native file export: `export_text_file` opens the macOS save panel on the Rust side. The webview can only suggest a sanitized file name, never a path. Writes are atomic (temp file + `sync_all` + rename) with a 256 MiB cap. Capability grants are limited to `core:event:allow-listen`/`allow-unlisten` and `core:window:allow-start-dragging`.

### Product: prompt folders and reader (requested during the audit)

- **Folders:** create, rename (Enter or click away), and delete (prompts move to Unfiled; Undo restores). Select a folder to see only its prompts. "New prompt" while a folder is open files the prompt there. The editor and reader both have a Folder picker. Folders are included in backups (`promptFolders`).
- **Reader:** clicking a prompt title or "Read full prompt", choosing it in ⌘K, or a starred shortcut opens a full-screen, read-only Monaco view of the exact text that will be copied. It has line numbers and word wrap, a Raw/XML/Markdown/JSON switcher, live variable inputs, and line/character/token counts. Copy with the button or ⌘↵; there is also an Edit button.
- **Editor:** the body field went from 8 rows to a resizable 18-row (min 320 px) monospace editor in a wider dialog. Every field now has a label.

### Correctness, accessibility, desktop

- Agent XML output escapes attribute values. Before, a title like `A <B> & "C"` produced invalid XML (reproduced with `DOMParser`).
- The app no longer invents descriptions: an empty prompt summary or stack tagline stays empty instead of filler text.
- The empty library no longer says "No matching prompts… clear filters". It distinguishes an empty library, an empty folder, and no matches.
- `useDialogFocus`: focus moves into dialogs, Tab is trapped, Escape closes, and focus returns to the opener. Verified with real keypresses in the reader. The toast is an `aria-live` region.
- macOS overlay title bar: the header is a `data-tauri-drag-region`, and the logo is inset 84 px so it no longer sits under the traffic lights (baseline screenshot showed the overlap).
- The `dev` script uses `--strictPort`. Before, Vite silently moved to :3001 while Tauri's `devUrl` kept loading whatever held :3000. That happened during this audit, with an orphaned server.
- `vp check src`: 10 warnings → 0.

## Blockers and honest gaps

- **Native interaction blocked.** `osascript` lacks Accessibility permission (`-1719`), so the native window could be screenshotted but not clicked. Verified natively by screenshot or process observation: rendering under the CSP, the traffic-light inset, and the quit flush handshake. Not verified natively: dragging the window by the header, the save panel, clipboard writes, and close-to-hide/Dock reopen. To unblock, grant Accessibility to the terminal/VS Code in System Settings (the user must do this), or check these manually: drag the window by the header, export a JSON backup, edit a prompt, then quit with ⌘Q and relaunch.
- **Chromium is not WebKit.** CSP and IndexedDB behaviour was verified in Chromium. WKWebView generally matches, but this is unverified.
- Signing and notarization are not configured. The bundle is unsigned, so on another Mac Gatekeeper will block it.
- No updater is configured.
